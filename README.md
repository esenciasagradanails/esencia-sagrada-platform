# Esencia Sagrada Nails - Platform

Masterclass landing page platform built with React, Vite, and modular SCSS.

## Features
- **Responsive Design**: Mobile-first architecture scaling seamlessly to desktop.
- **Dark Mode**: Integrated Redux state mapped to CSS variables for instant theme switching.
- **Animations**: Powered by Framer Motion for premium user interactions.
- **SCSS Modules**: BEM methodology with A-Z sorted properties for maintainable styling.
- **Vite Setup**: Fast HMR and optimized production builds.

## Setup
1. `npm install`
2. `npm run dev`

## Build
`npm run build`
